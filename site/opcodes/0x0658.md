# `0x0658` CMSG_CHARACTER_ADVANCEMENT_LOCK_ENTRY

**client to server** · status `hypothetical` · evidence `L3` · layout `named` · client code `sender`

Fiche: [`protocol/opcodes/0x0658-cmsg-character-advancement-lock-entry.yaml`](../../protocol/opcodes/0x0658-cmsg-character-advancement-lock-entry.yaml)

Lock a Character Advancement entry: the binding LockID(id) writes the id the UI passes (entry.ID / internalID in SpellListItem.lua, WildCardDice.lua) as one u32. Which of the two id spaces the UI names (entry id or internal id) is not settled by the calls alone.

| `entryId` | `u32` | L3 | the UI passes entry.ID or internalID depending on the caller |
