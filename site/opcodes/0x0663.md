One row of ChallengeModifiers.dbc: eight dwords then a NUL-terminated modifier-type token -- the family's only cstring, every other challenge patch packet length-prefixes its strings. The runtime record is dword-equal to the wire block (0x20 bytes) with the string pointer written over dword 4, which the reader skips.
