# `0x05A7` CMSG_CHALLENGE_CREATOR_SAVE_CHALLENGE

**client to server** · status `hypothetical` · evidence `L3` · layout `named` · client code `sender`

Fiche: [`protocol/opcodes/0x05a7-cmsg-challenge-creator-save-challenge.yaml`](../../protocol/opcodes/0x05a7-cmsg-challenge-creator-save-challenge.yaml)

The CoA server calls it `CMSG_COA_SAVE_TRIAL`.

Save a custom trial from the challenge creator: four length-prefixed strings, a count and that many (challengeId, level, description) entries; the server's HandleSaveTrial reads exactly that and answers 0x05A8 (TRIAL_SAVE_RESULT).
