# `0x09A0` SMSG_PATCH_QUEST_SORT

**server to client** · status `hypothetical` · evidence `L1` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x09a0-smsg-patch-quest-sort.yaml`](../../protocol/opcodes/0x09a0-smsg-patch-quest-sort.yaml)

The most reduced row in this shard. QuestSort.dbc has 18 columns (id + a 16-slot `name` locale block + its flags dword), but the wire sends only: id, one unnamed dword read off the wire but never stored anywhere by the handler (DBCStructure.h's comment calls it the name-flags mask), then ONE unnamed string (the whole 16-slot locale block, commented out in DBCStructure.h so not named here) with no placeholder dword for the block at all -- unlike every other locale table in this shard, which at least spends one skip-dword on it. 8 bytes fixed plus one string, against the table's 72-byte record.
