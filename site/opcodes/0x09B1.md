# `0x09B1` SMSG_SPELL_ACTIVATION_SHOW

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x09b1-smsg-spell-activation-show.yaml`](../../protocol/opcodes/0x09b1-smsg-spell-activation-show.yaml)

The CoA server calls it `SMSG_COA_SPELL_ACTIVATION_SHOW`.

Paint the spell-activation overlay (the proc glow) on the button of a spell: spell id, the overlay texture as a length-prefixed string (the server counts the NUL in the length), the overlay type, its scale and an RGB colour. The client fires SPELL_ACTIVATION_SHOW.
