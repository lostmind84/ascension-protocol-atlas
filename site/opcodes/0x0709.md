# `0x0709` SMSG_GM_TICKET_LIST

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x0709-smsg-gm-ticket-list.yaml`](../../protocol/opcodes/0x0709-smsg-gm-ticket-list.yaml)

The ticket list: a reset flag, a trailing-action flag, a count and that many ticket records. The record is the 0x110-byte GM ticket read by FUN_10248730, named after the Lua table the client builds from it.
