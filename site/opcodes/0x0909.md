# `0x0909` SMSG_MYTHIC_PLUS_PROGRESS_UPDATE

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x0909-smsg-mythic-plus-progress-update.yaml`](../../protocol/opcodes/0x0909-smsg-mythic-plus-progress-update.yaml)

The mythic+ progress packet: a count of changed encounters, then that many encounter IDs (each merged into the tracked-encounter map and fired as MYTHIC_PLUS_ENCOUNTER_UPDATE), then a trash-kill count and a champion-kill count, each fired as its own event only when it differs from what the client already holds.
