# `0x0596` SMSG_LIST_ACTIVE_CHALLENGES

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x0596-smsg-list-active-challenges.yaml`](../../protocol/opcodes/0x0596-smsg-list-active-challenges.yaml)

The CoA server calls it `SMSG_COA_CHALLENGE_ACTIVE_LIST`.

The player's active challenges, sent whole on login and after every change; the handler rebuilds its cache from it and fires CHALLENGE_ACTIVE_LIST_CHANGED with no arguments. One 26-byte record per challenge, block-copied by the client. Names of the two meaningful fields come from the server's writer (L1); the server writes constants into the other five.
