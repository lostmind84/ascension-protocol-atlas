# `0x05A4` CMSG_TOGGLE_GAME_MODE

**client to server** · status `hypothetical` · evidence `L3` · layout `named` · client code `sender`

Fiche: [`protocol/opcodes/0x05a4-cmsg-toggle-game-mode.yaml`](../../protocol/opcodes/0x05a4-cmsg-toggle-game-mode.yaml)

The CoA server calls it `CMSG_COA_TOGGLE_GAME_MODE`.

Toggle a custom game mode: a length-prefixed mode name then a u8 enable flag; the server reads u32 len at 0, the bytes, then u8 at 4+len (HandleToggleGameMode) and answers 0x05A5.
