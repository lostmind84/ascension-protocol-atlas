# `0x0603` CMSG_REFORGE_RANDOM_ENCHANT_ITEM

**client to server** · status `hypothetical` · evidence `L3` · layout `named` · client code `sender`

Fiche: [`protocol/opcodes/0x0603-cmsg-reforge-random-enchant-item.yaml`](../../protocol/opcodes/0x0603-cmsg-reforge-random-enchant-item.yaml)

Reforge the random enchant of an item: the binding ReforgeItem resolves its item argument to a container and a slot (FUN_10111d30/FUN_10111e20, with the +0x12/+0x16 offsets the client uses for equipped and bag slots) and writes them as two bytes.
