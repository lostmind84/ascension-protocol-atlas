# `0x09BD` SMSG_GAME_EVENT_INFO

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x09bd-smsg-game-event-info.yaml`](../../protocol/opcodes/0x09bd-smsg-game-event-info.yaml)

One 52-byte block, read as thirteen u32 and stored in a map keyed by the block's first u16; the byte at block +0x13 decides whether GAME_EVENT_STARTED or GAME_EVENT_ENDED fires. The capture reference's packets are 52 bytes too, so the two readings agree on the wire and differ only in how much of the block they decode; its field decode is carried here at L1.
