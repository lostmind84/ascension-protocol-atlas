# `0x05B6` SMSG_PATCH_CHALLENGE_REQUIREMENT

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x05b6-smsg-patch-challenge-requirement.yaml`](../../protocol/opcodes/0x05b6-smsg-patch-challenge-requirement.yaml)

The CoA server calls it `SMSG_COA_CHALLENGE_REQUIREMENT`.

One row of ChallengeRequirements.dbc: nine dwords then the RequirementType token as a length-prefixed string. The runtime record is dword-equal to the wire block (0x24 bytes) with the string pointer written over dword 4, which the reader skips. Five dwords are named from the offsets the detailedChallenge requirement builder at 0x1013c1a1 reads: the row key, RequirementType (the string) and MiscValue1-3.
