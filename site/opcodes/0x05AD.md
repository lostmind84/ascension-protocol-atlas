The CoA server calls it `CMSG_COA_ACTIVATE_TRIAL`.

Activate a custom trial: one length-prefixed trial id (the server's HandleActivateTrial reads it with ReadWireString and refuses an empty one); answered by 0x0x05AE (TRIAL_ACTIVATE_RESULT).
