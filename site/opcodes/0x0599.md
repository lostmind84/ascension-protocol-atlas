# `0x0599` SMSG_LIST_CHALLENGE_CRITERIA

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x0599-smsg-list-challenge-criteria.yaml`](../../protocol/opcodes/0x0599-smsg-list-challenge-criteria.yaml)

The CoA server calls it `SMSG_COA_CHALLENGE_CRITERIA_LIST`.

The criteria of the player's challenges, sent whole; the handler stores each 33-byte record at +0xc of a cache entry keyed by its second u32 and fires CHALLENGE_CRITERIA_LIST_CHANGED. The record is the one SMSG_UPDATE_CHALLENGE_CRITERIA 0x059A carries once, and the fields here are that fiche's: eight u32 and a done byte (33 = 8x4 + 1). The skeleton's two u64 were pairs of u32, the same misreading corrected on 0x059A.
