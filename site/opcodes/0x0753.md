# `0x0753` SMSG_DRAFT_STATE

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x0753-smsg-draft-state.yaml`](../../protocol/opcodes/0x0753-smsg-draft-state.yaml)

The whole draft-mode state, sent whenever it changes: a header of u32/u8 flags, then three counted lists -- (u32, u8, u8) entries, (u16, u16, u8, u8) entries and u32 entries -- after which the handler fires ASCENSION_DRAFT_STATE_UPDATED and, by what changed, the HAND_OF_FATE / DRAFT_PICK events (no arguments). The fields' meaning (picks, sacrifices, roles) is DraftUtil.lua's to read; not established from the binary.
