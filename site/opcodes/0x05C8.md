# `0x05C8` SMSG_CHALLENGE_COMPLETION

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x05c8-smsg-challenge-completion.yaml`](../../protocol/opcodes/0x05c8-smsg-challenge-completion.yaml)

The CoA server calls it `SMSG_COA_CHALLENGE_COMPLETION_ADDED`.

One leaderboard completion entry, inserted into the completion store and followed by CHALLENGE_COMPLETION_ADDED. Ten fields, read by the parser FUN_1013efd0: two u32, a length-prefixed name, two 64-bit times each read as a lo/hi pair, and three length-prefixed tokens. The record ends at +0x78 -- exactly the stride the handler advances by, so the map is complete. The first two dwords are the store key the Lua getter takes as (challengeID, level); the names of the three trailing strings come from the leaderboard model, whose key set forces them but whose order is the fork's.
