Nothing in this build constructs a packet with this opcode: no `push 0x54f` / `mov r32, 0x54f` occurs anywhere in Extensions.dll's `.text`, byte-exhaustively. The live feature applies appearances through the unified CMSG_APPLY_APPEARANCES (0x0697, registered and sent in this build -- not ours; `u32 count` + that many `u32 appearanceId`, the array indexed by appearance category), not through an outfit-id lookup. This is not "we have not found the sender yet"; it is "this build has no code that could send it."
