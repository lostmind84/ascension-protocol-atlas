# `0x064A` SMSG_PATCH_CHARACTER_ADVANCEMENT

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x064a-smsg-patch-character-advancement.yaml`](../../protocol/opcodes/0x064a-smsg-patch-character-advancement.yaml)

One CharacterAdvancement.dbc row, patched into the client's own copy of the catalogue: an id the handler range-checks against the table object, then the row's columns as a long mixture of u32 and NUL-terminated strings. Only the prefix below has been read; the handler assembles a 179-column record and the rest of it is not followed. The capture reference reports the packet as unused on a live realm, the client loading its catalogue from its own DBC instead.
