# `0x05B7` SMSG_PATCH_CHALLENGE_REWARD

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x05b7-smsg-patch-challenge-reward.yaml`](../../protocol/opcodes/0x05b7-smsg-patch-challenge-reward.yaml)

One row of ChallengeRewards.dbc: eleven dwords then two length-prefixed strings. The runtime record is dword-equal to the wire block (0x2c bytes) with the two string pointers written over dwords 4 and 5, which the reader skips. Only the row key is named; the reward model's own keys (ItemAmount, IsSpecialReward) are not pinned to offsets here.
