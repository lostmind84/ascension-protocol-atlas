# `0x059A` SMSG_UPDATE_CHALLENGE_CRITERIA

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x059a-smsg-update-challenge-criteria.yaml`](../../protocol/opcodes/0x059a-smsg-update-challenge-criteria.yaml)

The CoA server calls it `SMSG_COA_CHALLENGE_CRITERIA_UPDATED`.

A challenge criteria entry: eight u32 and a done byte, the client reading exactly that (the skeleton's two u64 were pairs of u32). Names from the fork's AppendCriteriaEntry/BuildCriteriaEntry, which it derived from this handler.
