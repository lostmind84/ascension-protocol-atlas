# `0x058D` SMSG_UPDATE_CONFIGS

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x058d-smsg-update-configs.yaml`](../../protocol/opcodes/0x058d-smsg-update-configs.yaml)

The CoA server calls it `SMSG_COA_CONFIG`.

The challenge config sync: five keyed sections -- ints, bools, two float sections and an optional list section -- each a count then (key, value) pairs; the client diffs them against what it holds and fires INT/BOOL/RATE_CONFIG_UPDATED(key, old, new). The fork's writer only sends the first section's shape.
