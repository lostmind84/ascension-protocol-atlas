# `0x05A6` SMSG_CHALLENGE_ACTIVE_UPDATE

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x05a6-smsg-challenge-active-update.yaml`](../../protocol/opcodes/0x05a6-smsg-challenge-active-update.yaml)

The CoA server calls it `SMSG_COA_CHALLENGE_DEATH_UPDATE`.

One active-challenge record (the 26-byte record of 0x0596), block-copied; the handler updates its cache entry and fires CHALLENGE_DEATH_UPDATE(challengeID, remainingLives, totalLives) with format %u%u%u. The two id fields are named from the server's writer (L1); the lives are among the fields the server currently writes as zero, and which is which is not established.
