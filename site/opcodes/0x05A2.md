Fiche: [`protocol/opcodes/0x05a2-smsg-challenge-query-failure-response.yaml`](../../protocol/opcodes/0x05a2-smsg-challenge-query-failure-response.yaml)

The CoA server calls it `SMSG_COA_CHALLENGE_FAILURE_LIST`.

The player's challenge failures, sent whole after CMSG_CHALLENGE_QUERY_FAILURE: a count and one record per failure; the client's handler reads the count and parses each record in a callee, then fires CHALLENGE_FAILURE_LIST_CHANGED. The record is the server's (L1: CoA.Challenges.History.cpp); an empty result is a single u32 zero.
