# `0x06E2` SMSG_INSPECT_CHARACTER_ADVANCEMENT_RESULT

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x06e2-smsg-inspect-character-advancement-result.yaml`](../../protocol/opcodes/0x06e2-smsg-inspect-character-advancement-result.yaml)

Result of inspecting a character's Advancement. A CA_INSPECT_* token; on CA_INSPECT_OK the inspected character's GUID, its active slot and slot count, then one complete known-entries block per slot -- the same 0x0726 body, read by the same deserializer (FUN_10166760). On any other token the packet is the string alone.
