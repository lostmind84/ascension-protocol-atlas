# `0x0613` CMSG_INSPECT_RANDOM_ENCHANTS

**client to server** · status `hypothetical` · evidence `L3` · layout `named` · client code `sender`

Fiche: [`protocol/opcodes/0x0613-cmsg-inspect-random-enchants.yaml`](../../protocol/opcodes/0x0613-cmsg-inspect-random-enchants.yaml)

Inspect another player's random enchants: the binding Inspect(unit, ...) resolves the unit token to its GUID and sends the 8 bytes (InspectFrame.lua calls it with self.unit). The server answers with the inspected enchants (0x0614/0x0615 by name).
