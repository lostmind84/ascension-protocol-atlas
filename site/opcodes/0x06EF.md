# `0x06EF` SMSG_UPDATE_WILDCARD_MISC_DATA

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x06ef-smsg-update-wildcard-misc-data.yaml`](../../protocol/opcodes/0x06ef-smsg-update-wildcard-misc-data.yaml)

One index worth of wildcard misc data, the same five u32 as a 0x06EE item, written for the index the service currently selects (no index in the packet). The three counters are compared with what was held and each change fires its WILDCARD_REPURCHASABLE_*_CHANGED event.

## Layout

| field | type | evidence | notes |
| --- | --- | --- | --- |
| `unknown_0` | `u32` | L3 | stored at the wildcard service +8 for the current index |
| `unknown_1` | `u32` | L3 | stored at +0x58 |
| `repurchasableRolls` | `u32` | L3 | compared with the value held before; a change fires WILDCARD_REPURCHASABLE_ROLLS_CHANGED(%u%u) |
| `repurchasableAbilityRolls` | `u32` | L3 | a change fires WILDCARD_REPURCHASABLE_ABILITY_ROLLS_CHANGED |
| `repurchasableTalentRolls` | `u32` | L3 | a change fires WILDCARD_REPURCHASABLE_TALENT_ROLLS_CHANGED |

## Client
