The CoA server calls it `SMSG_COA_CHALLENGE_SYNC_REQUEST`.

The server asks the client to sync its challenge state: a timeout and a list of (id, level) pairs the client stores, then CHALLENGE_SYNC_REQUEST fired with the timeout (format %u). Names from the server's writer (L1); the client reads exactly that.
