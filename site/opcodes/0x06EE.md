# `0x06EE` SMSG_LIST_WILDCARD_MISC_DATA

**server to client** · status `hypothetical` · evidence `L3` · layout `named` · client code `handler`

Fiche: [`protocol/opcodes/0x06ee-smsg-list-wildcard-misc-data.yaml`](../../protocol/opcodes/0x06ee-smsg-list-wildcard-misc-data.yaml)

Wildcard misc data for up to 20 indexes: five u32 per index, filed into five per-index arrays of the wildcard service. The last three are the repurchasable roll counters that 0x06EF updates one index at a time. The item is indexed by position, not by an id in the packet.
